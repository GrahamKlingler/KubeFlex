Visualization script `graph_overhead.py` producing three chart types from `overhead_raw.csv`: stacked bar chart (checkpoint/transfer/restore proportions), per-workload box plots (phase timing distributions), and summary statistics table (mean/median/std/min/max/p25/p75 per workload x phase) — all validated via `--validate` mode with synthetic sample data.

## What Was Built

### Task 1: graph_overhead.py (390 lines)

**CSV loading (`load_overhead_csv`):** Uses `csv.DictReader`, filters rows where `success == "true"`, converts all timing fields to float and `repetition` to int.

**Chart 1 — Stacked bar chart (`plot_stacked_bars`):** One bar per successful migration. X-axis labels encode workload, region pair, and repetition number. Three segments colored `#2196F3` (Checkpoint), `#FF9800` (Transfer), `#4CAF50` (Restore). Figure width scales with migration count. Saved as `stacked_bar_overhead.png`.

**Chart 2 — Box plots (`plot_boxplots`):** One subplot per workload (columns scale with workload count). Each subplot has three box plots for Checkpoint/Transfer/Restore phases. `patch_artist=True` with consistent phase colors applied to box faces. Saved as `boxplot_distributions.png`.

**Chart 3 — Summary statistics (`print_summary_table`):** Groups by (workload, phase). Computes n, mean, median, std, min, max, p25, p75 via numpy. Prints fixed-width table to stdout with separator lines between workload groups. Also saves `summary_stats.csv` via `csv.DictWriter`. Includes aggregate `all_workloads` rows.

**Validate mode (`validate()`):** Generates a 6-row sample CSV (2 workloads × 3 reps, deterministic via `random.seed(42)`), runs all three visualization functions, asserts output files exist, verifies summary CSV has 12 rows and all required columns, cleans up temp directory. Exits 0.
