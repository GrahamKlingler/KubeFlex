**File structure** (follow `graph_results.py` analog from 02-PATTERNS.md):

1. Shebang + docstring + imports:
```python
#!/usr/bin/env python3
"""
CRIU Migration Overhead Visualization

Reads overhead_raw.csv and produces:
1. Stacked bar chart — checkpoint/transfer/restore per migration
2. Box plots — timing distributions by workload type
3. Summary statistics table — mean, median, std, min, max, p25, p75

Usage:
    python3 graph_overhead.py <run_dir>
    python3 graph_overhead.py --validate  # generate sample data and test
"""

import argparse
import csv
import sys
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
```

2. CSV loading function `load_overhead_csv(csv_path)`:
- Use `csv.DictReader`
- Filter to rows where `success == "true"` 
- Convert numeric fields to float: checkpoint_ms, transfer_ms, restore_ms, total_ms
- Convert repetition to int
- Return list of dicts

3. **Chart 1: Stacked bar chart** — `plot_stacked_bars(rows, out_dir)`:
- One bar per successful migration, x-axis labeled as `"{workload}\n{src}->{tgt}\nR{rep}"`
- Three stacked segments: Checkpoint (color `#2196F3` blue), Transfer (`#FF9800` orange), Restore (`#4CAF50` green)
- Use `ax.bar(x, checkpoint, label="Checkpoint", color="#2196F3")`, then `ax.bar(x, transfer, bottom=checkpoint, ...)`, then `ax.bar(x, restore, bottom=checkpoint+transfer, ...)`
- Title: "CRIU Migration Overhead by Component"
- Y-axis: "Duration (ms)"
- X-axis: "Migration" with rotated labels
- Legend in upper right
- Figure size `(max(16, len(rows) * 0.4), 8)` to scale with migration count
- Save as `out_dir / "stacked_bar_overhead.png"` at dpi=150

4. **Chart 2: Box plots** — `plot_boxplots(rows, out_dir)`:
- Three subplots side by side (1 row, 3 cols): one per workload type
- Each subplot has 3 box plots for checkpoint, transfer, restore durations
- Group data by workload, then create arrays for each phase
- Use `ax.boxplot([checkpoint_data, transfer_data, restore_data], labels=["Checkpoint", "Transfer", "Restore"])`
- Title each subplot with workload name
- Y-axis: "Duration (ms)"
- Overall title: "Migration Phase Duration Distributions by Workload"
- Figure size `(16, 6)`
- Save as `out_dir / "boxplot_distributions.png"` at dpi=150

5. **Chart 3: Summary statistics table** — `print_summary_table(rows, out_dir)`:
- Group by (workload, phase) where phase is one of "checkpoint", "transfer", "restore", "total"
- For each group compute: n, mean, median, std, min, max, p25, p75 using numpy
- Print formatted table to stdout using fixed-width columns
- Also save as `out_dir / "summary_stats.csv"` via csv.DictWriter with columns: workload, phase, n, mean_ms, median_ms, std_ms, min_ms, max_ms, p25_ms, p75_ms
- Include aggregate rows: "all_workloads" combined

6. Main function `graph(run_dir)`:
- Load CSV from `run_dir / "overhead_raw.csv"`
- Call all three chart functions
- Print completion message with file paths

7. `--validate` mode:
- Generate a small sample CSV (6 rows, 2 workloads x 3 reps) with realistic-looking timing data
- Write to a temp directory
- Run all three visualization functions
- Verify output files exist
- Clean up temp directory
- Print "Validation passed"

8. `__main__` guard:
```python
if __name__ == "__main__":
    parser = argparse.ArgumentParser(description="Graph CRIU overhead benchmark results")
    parser.add_argument("run_dir", nargs="?", help="Path to run directory containing overhead_raw.csv")
    parser.add_argument("--validate", action="store_true", help="Generate sample data and validate visualization")
    args = parser.parse_args()
    if args.validate:
        validate()
    elif args.run_dir:
        graph(Path(args.run_dir))
    else:
        parser.print_help()
        sys.exit(1)
```

Key constraints:
- Use only matplotlib and numpy (no seaborn — not in project dependencies, per RESEARCH.md)
- Colors match RESEARCH.md code examples: `#2196F3` (checkpoint), `#FF9800` (transfer), `#4CAF50` (restore)
- All figures saved at dpi=150 with `bbox_inches="tight"` (per graph_results.py pattern)
- Summary stats use numpy: `np.mean`, `np.median`, `np.std`, `np.min`, `np.max`, `np.percentile(arr, 25)`, `np.percentile(arr, 75)`
