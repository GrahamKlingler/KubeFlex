Private helper `_hw_scaling(hw: HardwareSpec, reference_clock_ghz: float = REFERENCE_CLOCK_GHZ) -> float`:
Returns `reference_clock_ghz / hw.clock_speed_ghz` when `hw.clock_speed_ghz > 0`, else `1.0`. Values > 1 mean hw is slower than reference. Per D-04 (hardware scaling).

Public functions matching heuristic.txt signatures (per D-01):
- `ckpt_overhead(app_size_mb: float, src_hw: HardwareSpec) -> float`: Returns `(CKPT_SLOPE_S_PER_MB * app_size_mb + CKPT_INTERCEPT_S) * _hw_scaling(src_hw)` in seconds. Faster source = shorter checkpoint.
- `send_overhead(src_hw: HardwareSpec, dst_hw: HardwareSpec, app_size_mb: float) -> float`: Returns `TRANSFER_SLOPE_S_PER_MB * app_size_mb + TRANSFER_INTERCEPT_S` in seconds. No hardware scaling (network-bound). Signature matches heuristic.txt `send_overhead(src, dest, app_size)`.
- `restore_overhead(app_size_mb: float, dst_hw: HardwareSpec) -> float`: Returns `(RESTORE_SLOPE_S_PER_MB * app_size_mb + RESTORE_INTERCEPT_S) * _hw_scaling(dst_hw)` in seconds.
- `total_migration_time_s(app_size_mb: float, src_hw: HardwareSpec, dst_hw: HardwareSpec) -> float`: Sum of all three.
- `total_migration_time_h(app_size_mb: float, src_hw: HardwareSpec, dst_hw: HardwareSpec) -> float`: `total_migration_time_s(...) / 3600.0`

Each function has a docstring with Args/Returns in the style of runtime.py's `estimate_remaining_hours()`.

Import only: `from heuristics.hardware import HardwareSpec` (no sys.path.insert inside heuristics package).
